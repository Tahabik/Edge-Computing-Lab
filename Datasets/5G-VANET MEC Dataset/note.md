### About dataset

📌 Description:

This dataset is designed for real-time vehicular data processing 5G-enabled Vehicular Ad-hoc Networks using MEC. It simulates vehicle mobility, network conditios, and edge computing parameters to support ultra-low latency applciations is in smart cities.

The dataset is structured to facilitate machine learning tasks, including priority-based data processing, resource allocation optimization, and QoS enhancement in 5G-VARNET environments. The target variable (`Processing_class`) categorizes processing time into three levels:

Low (≤50 ms) – Fast Processing
Medium (51-150 ms) – Moderate Processing
High (>150 ms) – Slow Processing

📌 Key Features
✅ Vehicular Data: Speed, acceleration, traffic density, road type, weather conditions
✅ Network & Edge Features: MEC server load, latency, bandwidth, signal strength
✅ Priority-Based Features: Data type, urgency level, predicted priority
✅ Performance Metrics: Energy consumption, QoS score
✅ Target Column (Processing_Class): Categorical processing time classification
